# Claude Code & Claude Desktop Project Instructions

This repository is the **Universal Multimodal End-to-End Analysis Suite** for Images, Videos, and Websites.

Please refer to `setup/rules/AGENTS.md` for full autonomous protocols.

## Quick CLI Reference
- **Image Analysis**: `python core/launchers/analyze.py image <path>`
- **Video Analysis**: `python core/launchers/analyze.py video <path>`
- **Website Audit**: `python core/launchers/analyze.py website <url>`
- **Skill Routing**: `python core/launchers/analyze.py route "<prompt>"`
- **System Doctor**: `python core/launchers/analyze.py doctor`

Cross-platform compatible with Windows, macOS, and Linux.
MCP configuration available in `setup/config/mcp_config.json`.
